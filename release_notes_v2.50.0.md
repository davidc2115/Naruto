- 💾 **Sauvegarde fichier** - Format standard
- 🔄 **Import fichier** - Compatible

- ⏸️ **Contrôles** - Lecture, pause, arrêt

**TTSHelper** avec support Android TTS natif !

- 📸 **Database prête** - CustomGalleryImage

## 🛠️ OUTILS RECOMMANDÉS

### Générateurs IA Professionnels
1. **Midjourney** (Payant, meilleure qualité)
   - v6.1 pour hyperréalisme
   - Paramètres : `--style raw --quality 2 --ar 1:1`

2. **Stable Diffusion** (Gratuit, local)
   - Modèle : Realistic Vision v6.0 ou SDXL
   - Steps: 50+, CFG: 7-9

3. **Leonardo.ai** (Freemium)
   - PhotoReal mode
   - Resolution: 1024x1024+

4. **Pollinations.ai** (Gratuit, en ligne)
   - API simple à utiliser

### Paramètres Recommandés
- **Résolution** : 1024x1024 minimum (idéal 2048x2048)
- **Format** : JPG pour taille, PNG pour qualité
- **Style** : Photographie professionnelle, éclairage studio ou naturel
- **Poids** : < 200 KB par image (optimiser avec TinyPNG si > 500 KB)

## 📂 INSTALLATION DES NOUVELLES IMAGES

### Étape 1 : Générer les 16 images
Utilisez les prompts ci-dessus pour chaque personnage.

### Étape 2 : Renommer les fichiers
Assurez-vous d'avoir exactement ces noms :
```
naruto.jpg
sasuke.jpg
sakura.jpg
kakashi.jpg
hinata.jpg
itachi.jpg
brad.jpg
leonardo.jpg (supprimer leo.jpg si doublon)
rock.jpg
scarlett.jpg
margot.jpg
emma.jpg
zendaya.jpg
sofia_martinez.jpg
luna_chen.jpg
chloe_dubois.jpg
```

### Étape 3 : Optimiser les images
```bash
# Avec ImageMagick (si installé)
for img in *.jpg; do
    convert "$img" -resize 1024x1024^ -gravity center -extent 1024x1024 -quality 85 "optimized_$img"
done
```

Ou utilisez https://tinypng.com/

### Étape 4 : Copier dans le projet
```bash
cd /workspace/app/src/main/res/drawable-nodpi/

# Backup des anciennes images
mkdir -p backup
cp *.jpg backup/

# Copier les nouvelles
cp /chemin/vers/nouvelles/images/*.jpg .
```

### Étape 5 : Supprimer le doublon
```bash
rm leo.jpg  # Garder leonardo.jpg seulement
```

### Étape 6 : Recompiler
```bash
cd /workspace
./gradlew assembleRelease
```
